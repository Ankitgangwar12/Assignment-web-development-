Aim: To set up and verify the basic tools required for web development.

Tools Required:
Visual Studio Code (VS Code)
Node.js
npm (Node Package Manager)
Live Server Extension
Web Browser

Introduction:
Web development requires some basic tools to write, run, and test code. VS Code is used to write code, Node.js runs JavaScript outside the browser, npm manages packages, and Live Server helps us view HTML pages in a browser.

Procedure:
First, install and open Visual Studio Code on the computer.
Open the terminal in VS Code and type node -v to check the Node.js version.
Type npm -v to check the npm version.
Open the Extensions section in VS Code and search for Live Server.
Install the Live Server extension.
Create or open an HTML file in VS Code.
Right-click the HTML file and select Open with Live Server.
The webpage will open in the browser. Check that it is displayed correctly.
Take a screenshot showing the setup and save it as proof.

Result:
The basic web development tools were installed and checked. The HTML webpage was opened using Live Server, and a screenshot was taken as proof of the setup.
