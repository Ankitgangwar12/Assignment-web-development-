Aim:
To learn how to create a Git repository and save project changes using commits.

Introduction:
Git is a version control system used to track changes in files. A repository stores project files and their history. A commit saves a snapshot of the changes made to a project.

Important Git Commands:
git init – Creates a new Git repository.
git add – Selects files to be saved.
git commit – Saves changes in the repository.
git status – Shows the current status of files.
git log --oneline – Displays the commit history.
git config – Sets the user's name and email for Git commits.

Procedure:
Open the terminal on your computer.
Set your Git username and email.
Create a project folder and open it in the terminal.
Use git init to initialize the repository.
Create a README file describing the project.
Use git add to select the files.
Use git commit -m "message" to save the changes.
Repeat the process to create at least three meaningful commits.
Use git log --oneline to check the commit history.

Result:
A Git repository was created, and project changes were saved through meaningful commits.
