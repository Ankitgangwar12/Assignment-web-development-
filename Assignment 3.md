Aim:
To learn basic terminal commands used to create, view, copy, rename, and manage files and folders.

Introduction:
A terminal is a tool used to give commands to a computer. It helps us perform tasks such as creating folders, managing files, and opening projects in VS Code.

Basic Commands:
pwd – Shows the current folder location.
ls – Displays files and folders.
mkdir practice – Creates a folder named practice.
cd practice – Opens the practice folder.
cd .. – Moves one folder back.
touch index.html – Creates an empty file.
cp index.html backup.html – Copies a file.
mv backup.html old.html – Renames or moves a file.
cat index.html – Displays the contents of a file.
clear – Clears the terminal screen.
code . – Opens the current folder in VS Code.

Procedure:
Open VS Code on the computer.
Open the terminal.
Use the pwd command to check the current location.
Use the mkdir command to create a folder.
Use the cd command to enter or leave a folder.
Use file commands to create, copy, and rename files.
Use the ls command to check the files and folders.
Use code . to open the project folder in VS Code.

Result:
Basic terminal commands were practised to create and manage files and folders
